# deploy 文档索引

部署框架的可执行手册集中在这里。所有命令在服务端 `.189` 的
`/root/github/winter/deploy` 目录执行（本机 Windows 的 ansible 有 GBK locale 问题）。

| 文档 | 用途 |
| --- | --- |
| [manual.md](./manual.md) | **从零手动部署总手册**：前置 → 系统初始化 → 全组件 → HA → 迁移 → LVS → 验收 → 排障 → 回滚。按 tag 逐条命令，可直接复制执行。 |
| [etcd.md](./etcd.md) | **单独部署 etcd**：DCS 集群的独立入口（tag `etcd`）、前置、3 节点引导、健康验证、幂等性与重建。 |

## 文档约定

- 每篇手册的命令都在真机验证过，标注实测输出与验收点。
- 前置条件、配置项、验证命令、故障排查、重建步骤是必备章节。
- 命名遵循 ADR-50：配置项前缀 = 所属 role 的软件名（`etcd.*` / `winter_server.*` 等，见 ADR-50/52）。
- 新增组件手册时，同步更新本索引和总手册的对应章节。
