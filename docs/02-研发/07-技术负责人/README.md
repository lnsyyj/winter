# 技术负责人（TL / Tech Lead / Engineering Manager）

> 岗位族：**研发** — 怎么做出来
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

既是能打的工程师，也是带班班长

## 核心职责

- 拆解需求、分配任务，把控技术方案与代码质量
- 带教新人、组织代码评审
- 与产品/项目经理对齐进度并向上汇报

## 常见产出文档（岗位通用）

- 任务拆解清单
- 技术方案
- 代码评审记录
- 进度同步
