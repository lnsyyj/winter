# 前端工程师（FE / Front-end Engineer）

> 岗位族：**研发** — 怎么做出来
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

做用户看得见、点得动的界面

## 核心职责

- 把设计稿还原成网页界面与交互
- 调用后端 API 取数展示
- 处理多屏幕/浏览器兼容
- 配合测试修复界面缺陷

## 常见产出文档（岗位通用）

- 网页 / 小程序 / App 界面
- 接口联调记录
- 界面缺陷修复记录
