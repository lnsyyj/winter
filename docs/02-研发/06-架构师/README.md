# 架构师（Architect）

> 岗位族：**研发** — 怎么做出来
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

给系统搭骨架、定规矩，产出架构设计与技术规范

## 核心职责

- 设计系统整体结构：服务拆分、数据流向
- 制定技术选型与编码规范，解决性能、扩展性、安全性
- 重大项目技术决策与技术评审

## 常见产出文档（岗位通用）

- 架构设计
- 技术规范 / 编码规范
- 技术选型说明
- ADR 决策记录
- 技术评审记录
