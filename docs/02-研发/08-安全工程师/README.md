# 安全工程师（SEC / Security Engineer）

> 岗位族：**研发** — 怎么做出来
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

查漏洞、防攻击，给系统防盗

## 核心职责

- 安全测试（渗透测试、漏洞扫描）并推动修复
- 建立安全规范与应急响应机制
- 安全培训

## 常见产出文档（岗位通用）

- 安全报告
- 安全规范
- 应急响应方案
- 漏洞清单
