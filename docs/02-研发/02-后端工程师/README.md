# 后端工程师（BE / Back-end Engineer）

> 岗位族：**研发** — 怎么做出来
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

写看不见的业务逻辑和接口

## 核心职责

- 设计实现 API、业务逻辑、数据存取与权限校验
- 维护数据库结构
- 关注性能、并发、稳定性
- 配合运维部署、排查线上问题
