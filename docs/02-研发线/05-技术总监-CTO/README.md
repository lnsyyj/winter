# 技术总监 / CTO（技术负责人）

> 岗位线：**研发线** — 把想法变成能跑的代码 ｜ 原文第 **5** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

研发线最高负责人——把「技术语言」翻译成「生意语言」，是常被漏掉的角色。

## 核心职责

- 定技术战略：技术栈、上云与否、安全合规底线
- 管人管钱：招人、排兵布阵、分配预算
- 对外沟通技术可行性，避免销售承诺研发做不到的事
- 在多个可行方案之间做最终取舍，并为结果负责

## 常见产出

- 技术规划 / 技术战略
- OKR 与预算
- 人才梯队与组织设计
- 技术风险决策记录

## 在本项目中的落位（Ceph 管理平台）

- 技术栈收敛：Go + TypeScript + 少量 Python，不引入第四种语言 —— 每多一种，招聘与运维成本都翻倍。
- 自研边界：只自研管理面，存储能力一律用 Ceph 原生能力，绝不自己造存储。
- D1~D11 的最终拍板人；其中「内部自用还是私有化产品」决定后面所有投入方向，应最先定。
- 需要接受的成本：7 类有状态组件、六层版本矩阵（见权衡分析 §4），这是本设计的真实代价。
