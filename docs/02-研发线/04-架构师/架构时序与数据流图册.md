| 非对称 | 原因 |

  KMS["密钥库<br/>KMS / 文件密钥"] -->|"加解密密钥"| S

## 4. 时序图（13 条）

### 4.1 登录与会话（local / LDAP 双分支）

```mermaid
sequenceDiagram
    participant U as 浏览器
    participant NG as Nginx
    participant S as Server
    participant PG as 业务库
    participant L as LDAP（可选）

    U->>NG: POST /auth/login
    NG->>S: 转发（限流：用户名 + IP）
    S->>PG: 查用户（idp=local?）
    alt 本地账号
        S->>S: Argon2id 校验
    else 启用 LDAP
        S->>L: bind 服务账号 → search → 用用户凭据 re-bind
        L-->>S: user_dn + 组
        S->>S: role_map 映射（未命中 = 无权限）
        S->>PG: JIT 建用户（idp=ldap）
    end
    S->>PG: 写 refresh_tokens（存哈希）
    S-->>U: access JWT(15m) + refresh(7d) + CSRF
    U->>NG: 后续请求（Cookie）
    NG->>S: 透传
    S->>S: 验签 + exp
    S->>PG: 比对 token_version（缓存 ≤30s）+ jti 黑名单
    S-->>U: 200
    Note over S,PG: 登出 → jti 入黑名单；改角色 → token_version+1（≤30s 生效）
```

**失败分支**：LDAP 不可用 → 本地管理员仍可登录（break-glass）；密码错与用户不存在返回同一提示（防枚举）。

### 4.2 新建集群（Runner → Agent 切换）

```mermaid
sequenceDiagram
    participant S as Server
    participant ADB as 审计库
    participant PG as 业务库
    participant MQ as RabbitMQ
    participant RN as Runner
    participant A as Agent
    participant CE as cephadm/Ceph

    S->>ADB: intent（建集群）
    S->>PG: clusters + tasks(PENDING) + DAG
    S->>MQ: step-1 预检（executor=runner）
    MQ->>RN: 领取
    RN->>RN: SSH 跑 deploy/roles/prechecks（只读）
    RN-->>S: 结果（不改系统）
    S->>MQ: step-2 初始化（executor=runner）
    MQ->>RN: 领取
    RN->>A: 装 podman / Agent / 下发票据令牌
    Note over RN,A: Agent 上线，SSH 通道关闭
    S->>MQ: step-3 bootstrap（executor=agent）
    MQ->>A: A 拉取任务
    A->>CE: cephadm bootstrap（自行 pull 镜像）
    CE-->>A: FSID
    A-->>S: FSID + 步骤状态
    S->>PG: 回写 fsid / 凭据密文
    S->>MQ: step-4~6（add hosts / OSD / 服务）
    MQ->>A: 按 DAG 顺序
    A->>CE: orch apply / osd create
    A-->>S: SUCCEEDED
    S->>ADB: result 补写
    Note over S,CE: 任一步失败 → FAILED + 保留现场 + 人工重跑开新单
```

**评审关注**：step-1/2 一定不能由 Agent 做（那时它还不存在）；step-3 之后**不允许**再出现 SSH。

### 4.3 纳管已有集群（双通道）

```mermaid
sequenceDiagram
    participant U as 管理员
    participant S as Server
    participant RN as Runner
    participant A as Agent
    participant M as Ceph mgr

    U->>S: 纳管向导（地址/版本/凭据）
    alt 允许装 Agent → managed
        S->>RN: 下发任务（纳管窗口）
        RN->>A: SSH 装 Agent + 令牌
        A->>S: CSR 注册（mTLS 引导）
        S-->>A: 证书链
        A->>S: 后续走 mTLS 采集
    else 不允许装 Agent → limited
        S->>M: 校验 mgr dashboard 可用（只读 key）
        M-->>S: 版本 + 健康
        S->>S: capability=limited, collector=ceph_api
        Note over S,M: 只读采集；写任务在模板级 + 集群级双重拒绝
    end
```

**评审关注**：limited 拿不到 mgr API 时**必须明确失败**，不允许退回 SSH。

### 4.5 镜像拉取与失败诊断

```mermaid
sequenceDiagram
    participant S as Server
    participant A as Agent
    participant CE as cephadm
    participant HR as Harbor

    S->>A: 下发 registry 配置 + CA + 凭据
    A->>CE: cephadm bootstrap / orch apply
    CE->>HR: pull（image@sha256:...）
    alt 成功
        HR-->>CE: 镜像层
        CE-->>A: 容器启动

        A-->>S: step FAILED, error_code=image_pull_failed
    end

```

### 4.6 状态对账（Reconciler）

```mermaid
sequenceDiagram
    participant R as Reconciler（Server 内）
    participant A as Agent
    participant M as mgr API（limited）
    participant PG as 业务库

    loop 每 30s（按集群分片）
        R->>A: 拉 ceph -s / 拓扑（managed）

        end
    end
```

## 5. 端到端串演（一次「新建集群」跨 11 个进程）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户
    participant NG as Nginx
    participant S as Server
    participant ADB as 审计库
    participant PG as 业务库
    participant MQ as RabbitMQ
    participant RN as Runner
    participant A as Agent
    participant CE as cephadm/Ceph
    participant VM as VictoriaMetrics
    participant AM as Alertmanager
    participant VL as VictoriaLogs

    U->>NG: 登录 → 提交新建集群
    NG->>S: 转发
    S->>PG: 校验凭据（Argon2id/LDAP）+ 写 refresh
    S->>ADB: intent（建集群）
    S->>PG: clusters + tasks + DAG
    S->>MQ: step-1 预检（runner）
    MQ->>RN: 领取
    RN->>RN: SSH + prechecks（只读）
    RN-->>S: 结果
    S->>MQ: step-2 初始化（runner）
    MQ->>RN: 领取
    RN->>A: 装 podman + Agent + 注册令牌
    A->>S: CSR + 令牌
    S->>PG: agent_certs
    S-->>A: 证书链
    Note over RN,A: SSH 窗口关闭
    S->>MQ: step-3 bootstrap（agent）
    MQ->>A: 拉取
    A->>CE: cephadm bootstrap（pull 镜像）
    CE-->>A: FSID
    A-->>S: FSID + 状态
    A->>NG: 日志（mTLS）
    NG->>VL: 写入
    S->>ADB: result
    CE->>VM: 指标
    VM->>AM: 规则触发（如 CPU 高位）
    AM->>S: webhook
    S->>PG: alert_events
    S-->>U: WS 进度 + 告警 + HEALTH_OK
```

| 阶段 | 跨了哪些进程 | 关键不变式 |
| --- | --- | --- |
| 认证 | U→NG→S→PG | 角色在 JWT，改角色靠 ver 失效 |
| 预检/初始化 | S→MQ→RN→节点 | 仅此时用 SSH；凭据只在内存 |
| bootstrap | S→MQ→A→CE→Harbor | 无 SSH；镜像 digest 固定 |
| 观测 | A→NG→VL；CE→VM→AM→S | 日志不进 Server；告警幂等 |
| 收尾 | S→ADB | result 可缺，靠对账补 |
