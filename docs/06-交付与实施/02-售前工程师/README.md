# 售前工程师（SE / Presales Engineer）

> 岗位族：**交付与实施** — 怎么落地到客户现场、让项目通过验收
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

用技术方案帮销售赢单

## 核心职责

- 配合销售做产品演示与技术答疑
- 写解决方案、技术评估与报价支持
- 把客户需求反馈回产品团队

## 常见产出文档（岗位通用）

- 解决方案
- 演示材料
- 技术评估报告
- 报价单
