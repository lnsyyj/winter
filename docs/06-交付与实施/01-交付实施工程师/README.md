# 交付实施工程师（IMPL / Implementation Engineer）

> 岗位族：**交付与实施** — 怎么落地到客户现场、让项目通过验收
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

把软件装进客户现场并通过验收

## 核心职责

- 现场/远程完成部署、安装、配置与初始化
- 数据迁移与业务流程配置
- 培训用户、编写操作手册与上线方案
- 配合 UAT 验收与驻场支持

## 常见产出文档（岗位通用）

- 部署方案
- 配置记录
- 操作手册
- 上线方案
- UAT 材料
- 验收报告
