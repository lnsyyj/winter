# 产品经理（PM / Product Manager）

> 岗位族：**产品与设计** — 做什么、给谁用、长什么样
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

替用户做主、替公司算账的需求翻译官，决定做什么、排优先级

## 核心职责

- 调研用户和市场，弄清用户到底想要什么
- 把模糊想法写成 PRD：解决什么问题、长什么样、哪些情况不做
- 排优先级、和研发设计定排期
- 上线后看数据听反馈，决定下一步迭代

## 常见产出文档（岗位通用）

- PRD
- 原型 / 原型图
- 路线图
