# UI-UX设计师（UX / UI/UX Designer）

> 岗位族：**产品与设计** — 做什么、给谁用、长什么样
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

决定产品长什么样、好不好用

## 核心职责

- 根据需求出交互原型和视觉稿，定义按钮、配色、字体、间距
- 与产品确认功能逻辑、与前端确认可实现性
- 走查上线效果

## 常见产出文档（岗位通用）

- 交互原型
- 视觉稿 / 设计稿
- 设计规范
