# 项目经理（PM / Project Manager）

> 岗位族：**项目与流程** — 大家步调是否一致
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

盯人、事、时间、范围的总调度

## 核心职责

- 制定项目计划、拆解任务与排期
- 跟进进度、识别风险、协调阻塞
- 组织会议并同步进展

## 常见产出文档（岗位通用）

- 项目计划
- 进度报告
- 风险清单
- 会议纪要
- 复盘改进项
