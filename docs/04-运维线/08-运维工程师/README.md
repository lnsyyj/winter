# 运维工程师（Ops）

> 岗位线：**运维线** — 让系统别宕机 ｜ 原文第 **8** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

系统的「物业 + 保安」——部署上线、监控告警、备份容灾，出事第一个被找的人。

## 核心职责

- 部署上线、扩容迁移、日常巡检
- 盯监控告警，第一时间响应故障
- 备份与容灾演练，确认真能恢复
- 处理「服务器崩了 / 网络断了 / 磁盘满了」这类具体问题

## 常见产出

- 可复现的部署脚本
- 监控与告警配置
- 巡检记录 / 值班记录
- 故障处理记录

## 在本项目中的落位（Ceph 管理平台）

- 与 SRE 的边界：Ops 负责「装得上、看得见、出事有人接」，SRE 负责「用 SLO 和自动化让它自己稳」。
- 部署步骤见 [`部署与监控告警方案.md`](../09-SRE-DevOps/部署与监控告警方案.md) 与 [`安装部署手册.md`](../../07-新兴与稀缺线/20-技术文档工程师/安装部署手册.md)（命令待 D 系列决策定稿后补）。
- 值班口径必须写清：平台挂了不影响业务 IO，但会失去「新建 / 变更」能力 —— 不要按存储故障上报。
- 本岗位暂不单独建档，落位内容在 SRE 目录的两份文档中。
