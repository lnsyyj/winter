# DBA（数据库管理员）

> 岗位线：**运维线** — 让系统别宕机 ｜ 原文第 **10** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

看护数据库的「金库管理员」——备份、调优、权限，防止「删库跑路」式灾难。

## 核心职责

- 安装、配置、升级数据库，做备份与恢复演练
- 慢查询优化、索引与表结构设计
- 权限管控与数据安全
- 容灾方案与容量评估

## 常见产出

- 备份与恢复演练记录
- 表结构与索引设计
- 性能报告 / 慢查询分析
- 容灾方案

## 在本项目中的落位（Ceph 管理平台）

- 元数据库选 PostgreSQL（D2 待拍板）；只存元数据与任务/审计记录，**Ceph 的实际状态才是真相**。
- 最大隐患：任务表与审计表无界增长 → `audit_log` 按月分区 + 明确保留期（合规要求 ≥6 个月）。
- 必做的恢复演练：平台库整体丢失后，能否靠 Reconciler 从 Ceph 侧重建出可用状态。
- 本岗位暂不单独建档，相关约定分散在架构设计与安全设计中，待 D2 定稿后补「数据库运维手册」。
