# 测试工程师（QA / QA Engineer）

> 岗位族：**测试与质量** — 做得对不对
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

拿尺子验收产品的质检员

## 核心职责

- 根据需求写测试用例
- 执行测试、提交 bug 单并跟踪修复
- 上线前回归测试
- 参与需求评审

## 常见产出文档（岗位通用）

- 测试用例
- bug 单
- 测试报告
- 回归结论
