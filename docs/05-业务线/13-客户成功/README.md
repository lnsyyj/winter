# 客户成功（Customer Success，CS）

> 岗位线：**业务线** — 把软件卖出去、让客户满意 ｜ 原文第 **13** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

签单后陪客户「用得好、续费、增购」的人——不急着成交，盯长期满意度和续约。

## 核心职责

- 上线陪跑，帮客户把第一批集群纳管进来
- 跟踪客户健康度，提前发现要流失的信号
- 承接工单与回访，推动问题闭环
- 促成续约与增购，把使用深度转化为收入

## 常见产出

- 续约 / 增购记录
- 工单与回访记录
- 客户健康度报告
- 使用情况汇报

## 在本项目中的落位（Ceph 管理平台）

- 新版文章把「技术支持」并入本岗位：一线工单由 CS 承接，FAQ 与手册由技术文档工程师维护。
- 健康度信号可直接取平台数据：纳管集群数、任务失败率、告警未处理时长、活跃用户数。
- 续约谈判最有力的证据是「减少了多少次 SSH / 手工操作」，需要产品运营的采纳度报表支撑。
- 本岗位暂不单独建档，建议先建「客户健康度指标口径」再谈报表。
