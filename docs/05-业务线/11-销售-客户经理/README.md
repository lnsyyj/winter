# 销售 / 客户经理（Sales）

> 岗位线：**业务线** — 把软件卖出去、让客户满意 ｜ 原文第 **11** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

把软件卖出去的人——找客户、谈价格、签合同，拼的是信任和沟通。

## 核心职责

- 找客户、建关系、推进商机
- 谈价格、走合同流程、跟回款
- 把客户的组织结构与决策链摸清
- 把一线听到的竞品信息与拒绝理由带回公司

## 常见产出

- 合同
- 报价单
- 回款记录
- 商机与竞品信息

## 在本项目中的落位（Ceph 管理平台）

- 若走私有化交付：合同必须写明能力边界——不代理数据面、不承诺性能提升、依赖客户现有 Ceph 集群。
- B1 风险要提前认知：客户只有 1~2 套集群时，平台总成本高于手工运维，销售话术不能掩盖这点，否则验收必翻车。
- 「按集群数 / 节点数计价」比「按人头」更贴合价值，但需要产品侧先给出规模上限（PRD 待决策）。
- 本岗位暂不单独建档，能力边界清单建议由售前统一维护。
