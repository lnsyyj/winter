# 技术支持（SUPPORT / Technical Support）

> 岗位族：**市场与支持** — 有没有人用、好不好卖

- 通过工单、电话、在线聊天响应并记录跟踪
- 沉淀 FAQ 与知识库
- 把高频问题反馈给产品和研发
