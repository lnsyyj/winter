# 运维-SRE（SRE / Site Reliability Engineer）

> 岗位族：**运维与基础设施** — 能不能一直稳定跑
> 目录依据：[《软件行业的岗位》](https://lnsyyj.github.io/posts/software-industry-roles/) 的岗位族与速查表建立。

## 一句话定位

上线后常年守在楼里的物业

## 核心职责

- 部署维护线上服务器与集群，处理发布、扩容、迁移
- 搭监控告警，发现并处理故障
- 容量规划与成本控制
- 推动自动化

## 常见产出文档（岗位通用）

- 部署方案 / 发布记录
- 监控与告警体系说明
- 容量规划
- 故障结论
