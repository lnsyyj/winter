# 数据工程师（Data Engineer）

> 岗位线：**新兴与稀缺线** — 市场上还缺、正在冒头的职业 ｜ 原文第 **18** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

数据分析师的上游——保证「数从哪来、准不准」，让分析师随时取用。

## 核心职责

- 搭数据管道（pipeline），把散落各处的数据洗干净、打通
- 维护数据仓库与指标层
- 保证数据准时、准确、可追溯
- 为分析与模型提供稳定的数据底座

## 常见产出

- 数据管道 / ETL 说明
- 数仓模型与指标层定义
- 数据质量校验规则
- 数据字典

## 在本项目中的落位（Ceph 管理平台）

- 采集侧三源：VictoriaMetrics（指标）、VictoriaLogs / Loki（日志）、PostgreSQL（任务与审计）。
- 最该先建的是「任务事件流」：任务开始 / 重试 / 失败 / 完成 → 可回放，既服务分析也服务测试。
- 与 SRE 的边界：SRE 负责采集与保留策略，数据工程师负责建模与口径。
- 本岗位暂不单独建档，等指标口径表落地后再补数据字典。
