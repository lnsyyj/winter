# 算法 / AI 工程师（Algorithm / ML / LLM Engineer）

> 岗位线：**新兴与稀缺线** — 市场上还缺、正在冒头的职业 ｜ 原文第 **17** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

让系统「会思考」的人——开发写确定逻辑，AI 工程师调概率模型。

## 核心职责

- 喂数据 → 训练模型 → 评估 → 部署推理服务
- 做推荐、图像识别、异常检测，或调大模型（LLM）
- 把效果转成可衡量的指标，而不是「感觉变好了」
- 与工程配合把模型稳定地跑在生产上

## 常见产出

- 模型与训练脚本
- 推理服务 / API
- 评估报告（含基线对比）
- 特征与数据说明

## 在本项目中的落位（Ceph 管理平台）

- 本项目可落地的三件事：告警聚合与根因推荐、容量 / 增长预测、OSD 抖动等异常检测。
- 明确不做：v1 不做「自动自愈」—— 概率模型不能直接触发不可逆的物理操作，只能给建议。
- 前置条件：先把指标与任务事件沉淀干净（依赖数据工程师），否则没有可信的训练数据。
- 本岗位暂不单独建档，属 V2 之后的能力，当前不应进入排期。
