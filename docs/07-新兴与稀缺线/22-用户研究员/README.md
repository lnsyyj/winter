# 用户研究员（UX Researcher）

> 岗位线：**新兴与稀缺线** — 市场上还缺、正在冒头的职业 ｜ 原文第 **22** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

设计师的「情报员」——不画界面，用访谈和测试搞清用户到底在想什么。

## 核心职责

- 做用户访谈、问卷、现场观察
- 做可用性测试，找出用户卡在哪一步
- 输出研究报告，让产品在动手前就有依据
- 建立用户画像与典型场景

## 常见产出

- 研究报告
- 访谈记录 / 观察笔记
- 可用性问题清单
- 用户画像与场景地图

## 在本项目中的落位（Ceph 管理平台）

- 研究对象是运维同学：现在怎么用 `ceph -s`、Ceph Dashboard、Ansible，卡在哪一步。
- 最该问清的问题：他们真正怕的是「平台替我做不可逆操作」，还是「操作太繁琐」？两者对应完全不同的产品。
- 可用性测试脚本：让运维在无人指导下完成「纳管一套已有集群」，记录第一次卡住的位置。
- 本岗位暂不单独建档；建议在 M0 期间先做 5 场访谈，结论直接进 PRD 的用户角色章节。
