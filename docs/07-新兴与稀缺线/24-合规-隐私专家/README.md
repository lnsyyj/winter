# 合规 / 隐私专家（Compliance / Privacy）

> 岗位线：**新兴与稀缺线** — 市场上还缺、正在冒头的职业 ｜ 原文第 **24** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

帮公司「别踩法律红线」的人——风险前置，上线前解决比被罚后补救便宜一万倍。

## 核心职责

- 管数据合规：个人信息保护法、GDPR、等保要求
- 做合规审计与隐私影响评估
- 应对监管检查，准备材料与整改
- 在需求阶段就拦掉高风险设计（如无必要的数据采集）

## 常见产出

- 合规报告 / 评估结论
- 审计报告与整改清单
- 数据保留与销毁策略
- 隐私影响评估（PIA）

## 在本项目中的落位（Ceph 管理平台）

- 审计日志保留期 ≥6 个月（等保要求），必须与 DBA 的分区 / 清理策略一致，否则合规与性能互相打脸。
- 平台账号属个人信息：最小化采集、离职即回收、操作可追溯；不要顺手存手机号。
- 私有化交付时客户数据不出场：平台不应有任何「回传」行为，需在架构上显式声明并可验证。
- 本岗位暂不单独建档；建议在 MVP 上线前补一份「数据留存与删除策略」作为安全设计的附件。
