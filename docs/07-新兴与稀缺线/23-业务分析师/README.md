# 业务分析师（Business Analyst，BA）

> 岗位线：**新兴与稀缺线** — 市场上还缺、正在冒头的职业 ｜ 原文第 **23** 个岗位
> 依据：[《软件行业岗位全景图》](https://lnsyyj.github.io/posts/software-industry-job-roles/)（7 条线 / 24 岗版）

## 一句话定位

业务方和研发之间的「翻译官」——把「我要提升效率」翻译成可执行清单。

## 核心职责

- 梳理现状流程，找出真正的时间去哪了
- 把模糊诉求拆成「做 3 个功能、改 2 张表」
- 画业务流程图、写需求清单与规则说明
- 在政企 / 金融项目里对齐多方口径，避免验收争议

## 常见产出

- 需求清单
- 业务流程图 / 现状与目标对比
- 规则与字段说明
- 验收依据

## 在本项目中的落位（Ceph 管理平台）

- 典型翻译：把「运维太累」拆成「纳管 N 套集群、减少 M 次 SSH、建集群从 2 天到 2 小时」。
- 政企 / 金融客户场景里，BA 输出的流程图常直接成为验收依据，要能被客户签字确认。
- 与产品经理分工：BA 靠业务侧、写清现状与规则；PM 定产品形态与优先级。
- 本岗位暂不单独建档；需求清单可直接作为 PRD 的输入附件。
